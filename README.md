# 合成大豆包

一款移动端优先的“合成大西瓜”式趣味游戏。图标从 Mira 开始逐级合成为 Doubao Dance；两个 Doubao Dance 相遇后会生成一个真实豆包留在场内，并在容器底部升起一座“勇攀高峰”，永久压缩剩余空间。

## 游戏规则

- 拖动选择投放位置，松手投放图标。
- 两个相同等级的图标碰撞后合成下一级，并增加“字节范儿”。
- 两个 Doubao Dance 相遇后合成一个留在场内的大豆包，同时累计一座高峰。
- 手机与电脑统一使用 390×560 逻辑棋盘，只做等比显示，难度保持一致。
- 碰撞沿用初版的速度、旋转、回弹与位置修正参数，仅在高速移动时增加物理子步防止穿模。
- 图标持续越过警戒线 2.5 秒后结束，并生成年度总结。
- 年度绩效要求至少登上 1 座高峰：3000 以下或 0 座高峰为 I、3000–3999 为 M-、4000–4999 为 M、5000–5999 或至少 2 座高峰为 M+、6000 及以上或至少 3 座高峰为 E。
- 结算图先展示为可长按保存的 1080×1440 PNG，再选择微信好友、朋友圈、系统分享、下载或复制链接。
- 独立数据看板统计去重游玩人数、游戏场次、转发动作和渠道，不在玩家游戏界面外显；GitHub Pages 与原站共用独立 API。
- 历史最高分和最高峰数保存在当前设备。

## 本地运行

```bash
npm install
npm run dev
```

GitHub Pages 静态构建：

```bash
npm run build:pages
```

验证：

```bash
npm test
npm run lint
```

## 图标资源

正式图标放在 `public/icons/`。具体文件名与尺寸要求见该目录中的 `README.md`；缺少资源时，游戏会自动显示几何占位符。

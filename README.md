# 组织碰撞实验

一款移动端优先的“合成大西瓜”式趣味游戏。图标从 Mira 开始逐级合成为 Doubao Dance；两个最高级图标相遇后会消失，并在容器底部升起一座“勇攀高峰”，永久压缩剩余空间。

## 游戏规则

- 拖动选择投放位置，松手投放图标。
- 两个相同等级的图标碰撞后合成下一级，并增加“字节范儿”。
- 两个 Doubao Dance 相遇后消失，累计一座高峰。
- 图标持续越过警戒线 2.5 秒后结束，并生成年度总结。
- 历史最高分和最高峰数保存在当前设备。

## 本地运行

```bash
npm install
npm run dev
```

验证：

```bash
npm test
npm run lint
```

## 替换正式图标

图标文件放在 `public/icons/`。具体文件名与尺寸要求见该目录中的 `README.md`。缺少正式图标时，游戏会自动显示几何占位符。
